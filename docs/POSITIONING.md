# 定位：新型 Agent 会是什么样的

> 本文是思考稿，不是规格。可核实的事实与模式推理分开标注。
> 写作日期：以仓库最近提交时间为准。作者：与用户讨论后的夜间思考。

## 一、那个问题的结构：为什么 OpenClaw 在 pi 之后才出现

先核对事实。pi（earendil-works）是 agent 基础设施层：统一 LLM API（pi-ai）、带工具调用与事件流的 agent loop（pi-agent-core）、会话/回放/遥测（harness/session）、编码 agent CLI。它解决的是"一次 agent 运行怎么可靠地发生"。OpenClaw 解决的是另一个问题："一个 agent 怎么住进一个人的日常通信里"——通过 WhatsApp/Telegram 之类的既有渠道、由社区共同养育、最终开源。

所以"为什么没有更早出现"的答案是分层的，不是灵感的：

1. **能力先于持久性**。在 agent loop 尚不可靠的年代，先被攻克的是"可靠地完成一次运行"。pi 这类基础设施就是那个年代的产物。只有当单次运行变得廉价、可靠、可组合，下一层的问题——"多次运行之间留下什么"——才值得被提出。
2. **分发先于关系**。OpenClaw 借道已有消息渠道，绕开了"再装一个 app"的摩擦。它验证的是个人 agent 的分发形态，不是记忆架构。
3. **成本曲线决定入场时机**。推理成本每十八个月掉一个量级，常驻型 agent（随时在、随手聊）的经济可行性是最近才成立的。

一层成熟，上面一层才成为问题。**OpenClaw 出现得晚，不是有人没想出来，是它的生态位直到上一层面铺好之后才存在。**（"dsh" 所指未能在本次写作中核实，无法给出事实性陈述；但其出现逻辑与上文同一模式：每个基础设施层成熟后，其上一层自然涌现。）

## 二、为什么"超长生命周期"至今没有产品化：商业模式三禁令

GrandEunuch 想要的东西，商业产品在结构上无法提供：

1. **休眠禁令**。真正的长周期关系允许主人三个月不回来。留存指标不允许。
2. **遗忘禁令**。长周期记忆必须能真忘（旧账会压垮新判断）。数据护城河不允许。
3. **换脑禁令**。十年里模型会换很多代，记忆必须与任何模型解耦。锁定策略不允许。

这解释了为什么"终身助手"不会首先出现在平台公司：**它需要的是与其收入结构相反的东西——少打扰、真遗忘、可迁移。** 只有"自己养、自己用、数据归自己"的本地系统才做得起这个形态。这是 GrandEunuch 的存在理由，不是工程偏好。

## 三、GrandEunuch 的位置：生命周期层

类比两个早已存在的层：

- **文件系统**在应用之下：应用一代代死去，文件活着。
- **日历**在设备之间：语义（时间）不属于任何一台设备。

GrandEunuch 想占据的是模型的上面一层、应用的下面一层：**记忆与脾气层**。它不属于任何模型（模型是租来的脑子），也不属于任何应用形态（对话界面只是当前时代的操作界面）。它拥有的语义是：什么值得留下（provenance）、什么正在淡出（修订/归档/遗忘）、什么此刻值得被重新提起（上下文装配）、什么时候允许开口（唤醒与打扰预算）。

用两个名词说：知识库负责活过时间，上下文管理负责此刻显形。二者之间长出的全部策略，就是"脾气"。spec v1.0 已经写完了这层的一半——决策权边界（空间契约）；v1.1 要写的是另一半——时间契约。

## 四、自进化：超长生命周期与它的关系

用户的直觉："超长生命周期更偏向自进化。" 需要拆开。

**生命周期不是自进化的结果，是它的容器。** 没有可追溯、可回滚、可遗忘的十年积累，任何"自我修改"都是自毁。进化 = 变异 + 选择 + 保留。对照现状：

| 进化的要素 | 对应机制（已存在或已有雏形） |
|---|---|
| 变异 | Agent 提出策略修改：年度回顾中"我认为这条该忘、那个习惯该改" |
| 选择 | 用户的真实使用：摩擦日志即 fitness function，预 commit 的决策表即选择规则 |
| 保留 | provenance、版本链、CAS 修订、两阶段遗忘——变异必须留下痕迹、可回滚 |

所以自进化在 GrandEunuch 里的形态不是"模型自己改自己"，而是：

1. **行为策略**（说话分寸、提醒时机）作为记忆中的用户决定与使用事实而存在，随积累自然漂移；
2. **维护仪式**（大扫除）由 Agent 提案、用户批准——人类是选择压，这是故意的，不是妥协；
3. **high-impact 变更永不无人监督**——这已经是 spec 的立场（forget 需要用户确认）。

超长生命周期真正要求的不是更强的自进化能力，而是**更严的演化纪律**。十年尺度上，一个错误的自我修改比一个错误的内存操作贵一万倍，因为它污染的是之后所有判断的基线。

## 五、颠覆在哪里

不在更强，在更久。行业目前把 agent 当工具卖——能力是租来的，每六个月同几家实验室刷新一次，人人都有。GrandEunuch 把 agent 当**资产**养：记忆是本金，provenance 是复利，脾气是随着共同历史长出来的东西。

一句话定位：**能力是租的，记忆是攒的，脾气是养的。别人换更强的脑子，我们攒更厚的自己。**

革命性不来自任何单点技术，来自一个此前被商业模式禁止的承诺：**一个愿意等你的东西。**
